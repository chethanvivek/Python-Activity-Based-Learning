# Algorithm

1. Start.
2. Set the number of students to 3 and the number of subjects to 3.
3. Create an empty nested list to store marks.
4. Repeat for each student:
   a. Create an empty list for the student's marks.
   b. Read marks for all 3 subjects.
   c. Check whether each mark is between 0 and 100.
   d. If any mark is invalid, display an error message and stop.
   e. Add the student's marks to the nested list.
5. If all marks are valid:
   a. Calculate each student's total and average marks.
   b. Calculate the total marks obtained in each subject.
   c. Calculate the average marks of each subject.
   d. Identify the student with the highest total marks.
   e. Identify subjects with an average below 40.
6. Display student-wise totals and averages.
7. Display subject-wise averages.
8. Display the top-performing student.
9. Display subjects with low average performance.
10. Stop.
