# Assumptions

1. The program analyses 3 students and 3 subjects.
2. Each subject is evaluated for 100 marks.
3. Marks must be between 0 and 100.
4. A subject is considered to have low performance if its average marks are below 40.
5. The top-performing student is the student with the highest total marks.
6. If two students have the same highest total, the first student entered is considered the top performer.
7. The program assumes that the user enters numeric marks.
