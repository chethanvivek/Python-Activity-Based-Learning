# Problem Statement

Develop a Python program to calculate a student's current attendance
percentage and determine the minimum number of upcoming classes required
to reach the minimum attendance eligibility threshold.

The program should evaluate different future attendance scenarios,
such as attending 100%, 90%, and 80% of upcoming classes.

It should display the current attendance percentage and the minimum
number of future classes required to achieve the eligibility threshold
under each scenario. If the threshold cannot be reached under a
particular scenario, the program should display an appropriate message.
