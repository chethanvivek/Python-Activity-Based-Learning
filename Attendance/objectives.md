# Objectives

1. Accept the number of classes attended by the student.
2. Accept the total number of classes conducted.
3. Calculate the current attendance percentage.
4. Compare current attendance with the minimum eligibility threshold.
5. Evaluate future attendance scenarios of 100%, 90%, and 80%.
6. Calculate the minimum number of upcoming classes required to reach
   the eligibility threshold under each scenario.
7. Identify scenarios in which the eligibility threshold cannot be reached.
8. Display the results clearly.
