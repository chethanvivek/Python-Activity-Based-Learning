# Problem Statement

Develop a Python program to analyse a student's performance across multiple examinations.

The program should:

- Accept marks for 3 subjects across 3 examinations.
- Calculate the average marks for each subject.
- Compare the marks between the first and third examinations to identify improvements or declines.
- Identify subjects in which the student consistently performs poorly.
- Calculate the overall average and classify the student's performance based on predefined criteria.
