# Assumptions

1. The program analyses 3 subjects.
2. Each subject has marks from 3 examinations.
3. Each examination is conducted for 100 marks.
4. Marks must be between 0 and 100.
5. A subject is considered consistently weak if its average marks across all three examinations are below 40.
6. Performance is compared using the first and third examination marks.
7. Overall performance classification:
   - 75 and above: Excellent
   - 60 to below 75: Good
   - 40 to below 60: Average
   - Below 40: Needs Improvement
8. The program assumes that the user enters numeric marks.
