# Algorithm

1. Start.
2. Set the number of subjects to 3.
3. Create an empty list to store subject averages.
4. Set the overall total to 0.
5. Repeat for each of the 3 subjects:
   a. Read marks for Examination 1.
   b. Read marks for Examination 2.
   c. Read marks for Examination 3.
   d. Check whether all marks are between 0 and 100.
   e. If any mark is invalid, display an error message and stop.
   f. Calculate the subject average.
   g. Add the subject average to the overall total.
   h. Compare Examination 1 and Examination 3 marks.
   i. Display whether the subject improved, declined, or remained unchanged.
   j. If the subject average is below 40, identify it as consistently weak.
6. Calculate the overall average using the 3 subject averages.
7. Classify the student's performance:
   - 75 or above: Excellent.
   - 60 or above: Good.
   - 40 or above: Average.
   - Below 40: Needs Improvement.
8. Display the overall average and performance classification.
9. Stop.
