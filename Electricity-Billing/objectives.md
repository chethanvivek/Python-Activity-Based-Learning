# Objectives – Progressive Electricity Billing

1. To calculate household electricity bills based on multiple consumption slabs.
2. To apply fixed charges, surcharges, and applicable rebates.
3. To calculate the total electricity bill accurately.
4. To compare electricity bills across multiple months.
5. To identify unusual increases in electricity consumption and billing amounts.
6. To validate user inputs and handle invalid values.
7. To develop problem-solving skills using Python variables, operators, conditional statements, loops, and lists.
