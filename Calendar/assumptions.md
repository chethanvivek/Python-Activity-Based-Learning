# Assumptions

1. The starting weekday is entered as a number from 1 to 7.
2. Sunday = 1, Monday = 2, Tuesday = 3, Wednesday = 4, Thursday = 5, Friday = 6, Saturday = 7.
3. The number of days in the month must be between 28 and 31.
4. The program generates one month at a time.
5. The user enters valid numeric inputs.
6. The calendar does not require a month name or year.
