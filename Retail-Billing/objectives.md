# Objectives – Employee Payroll and Deduction Analysis

1. To calculate overtime pay based on overtime hours and hourly rate.
2. To calculate the gross salary using basic pay, allowances, overtime pay, and incentives.
3. To apply deductions using progressive deduction slabs.
4. To calculate the employee's net salary after deductions.
5. To generate a formatted salary statement.
6. To validate inputs and reject negative values.
7. To apply Python variables, arithmetic operators, conditional statements, and functions.
